# CAR-Cytotox
This is an online calculator for the CAR‑Cytotox score (0–10) to determine CAR-related cytotoxicity for research purposes. Enter per‑marker fold changes (Stim/Unstim; for RT‑qPCR use 2−ΔΔCt). The calculator uses locked 90th‑percentile anchors from healthy donors and the predefined weights.
